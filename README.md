# Pavan Chaitanya WorkTrack
Personal engineering work management PWA. v0.4 adds a lifetime Time Logger with manual entries and a start/stop timer. Time logs are stored in the existing WorkTrack data object, so they participate in existing local backup and Google Apps Script cloud sync. Keep private tokens and backup JSON files out of GitHub.

## Update
Upload the updated `index.html` to the root of your existing GitHub Pages repository. Keep your existing `manifest.webmanifest` and `sw.js` unless separately updated. After deployment, hard-refresh the site (Ctrl+Shift+R). Export a full JSON backup first.
