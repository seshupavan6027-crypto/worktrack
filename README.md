# Pavan Chaitanya WorkTrack v0.9

Premium interface refresh for the personal engineering work tracker.

## What's visibly updated
- Version badge in the sidebar.
- Refined premium dashboard styling, cards, buttons and responsive layout.
- Clear storage banner that distinguishes local storage from configured Google Drive sync.
- Updated service-worker cache version so installed PWAs fetch the new interface.

## Important
- Existing local browser data format and Google Apps Script sync code are preserved.
- The app still needs the user's own Apps Script URL and private token configured in Settings.
- This package does not contain or require your private token.
- Back up your WorkTrack data before replacing the files on GitHub Pages.
