Pavan Chaitanya WorkTrack v0.6 – Evergreen visual refresh

This update refreshes the visual palette to a calm evergreen/teal and warm ivory theme, improves card ambience, and fixes task checkbox sizing so task rows do not collapse into narrow columns.

Deployment:
1. Back up WorkTrack data from Settings & Backup.
2. Replace only index.html in the GitHub Pages repository with this version.
3. Keep the existing manifest.webmanifest and sw.js unless intentionally updating them.
4. Commit once and wait for the latest Pages deployment to finish.
5. Hard refresh the site (Ctrl+Shift+R).

This is a visual/CSS update based on the supplied v0.5 package. It does not add new backend features or change the Google Apps Script endpoint.
